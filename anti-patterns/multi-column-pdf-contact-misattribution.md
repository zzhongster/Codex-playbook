# 反模式：把多栏 PDF 的文本顺序当成记录边界

## 一句话结论

多栏名录经文本提取或 OCR 后，相邻栏位可能被交错或串联；联系人只能在同一页面、同一栏和同一条目边界内归属，不能根据扁平文本中的名称邻近关系配对。

## 场景

调研公司时，需要从商会名录、会员名单、企业选民册或政府登记 PDF 中提取公司负责人。原始页面左右各有一组独立企业条目，每条包含编号、公司名、地址、负责人、电话和注册信息。

使用搜索结果摘要、OCR 或普通 `pdftotext` 后，页面被压成单一文本流。目标公司附近恰好出现一个人名，于是该人被记录成目标公司的负责人。

## 失败表现

- 左栏目标公司的字段与右栏相邻公司的负责人被拼成一条记录。
- 同一个联系人被错误分配给两家相邻公司。
- 文本内容都真实存在，但“联系人属于哪家公司”这一关系是错误的。
- 后续搜索不断引用首次错误归属，使低质量推断看起来像多来源确认。
- 报告给出错误采购联系人，实际触达后才发现对方属于另一家公司或业务线。

## 根因

PDF 保存的是带坐标的文本对象，不保证内容流与人眼看到的阅读顺序一致。文本提取器和 OCR 可能采用以下任一种顺序：

- 先读取一行的左栏，再读取同一高度的右栏；
- 先读取整页左栏，再读取整页右栏；
- 根据内容流对象顺序输出，与视觉顺序无关；
- 把跨栏的相近基线误判为同一个表格行。

真正的记录关系由版面几何、栏位和条目边界决定，不由扁平文本中的前后距离决定。把“名称出现在公司名附近”当作归属证据，等于丢失了最关键的结构信息。

## 正确做法

### 1. 保留页面级视觉证据

先固定 PDF、页码和目标条目编号，再渲染对应页面：

~~~bash
pdftoppm -f 13 -l 13 -r 200 -png directory.pdf page
~~~

在原始页面上确认目标公司位于哪一栏，并标出该条目的上、下边界。不要只阅读搜索摘要或复制出来的文本。

### 2. 使用保留布局或坐标的提取方式

~~~bash
pdftotext -layout directory.pdf directory.layout.txt
pdftotext -bbox-layout directory.pdf directory.bbox.html
~~~

`-layout` 适合快速检查栏位；`-bbox-layout` 提供文字坐标，适合程序化分栏和记录分组。扫描件应先 OCR，但仍需保留每个词或文本块的坐标。

### 3. 先分栏，再分条目

推荐的解析顺序是：

~~~text
page
  -> column region by x range
  -> record boundary by entry number/company anchor
  -> fields inside that record
  -> contact-to-company assertion
~~~

禁止先把整页转成字符串，再用公司名附近固定字符数或固定行数寻找人名。跨栏文字即使 `y` 坐标接近，也不能自动属于同一条记录。

### 4. 对每个归属关系保存最小证据

联系人归属至少记录：

| 字段 | 作用 |
| --- | --- |
| PDF 来源和版本 | 固定原始证据 |
| 页码、条目编号 | 固定记录位置 |
| 栏位或 `x` 范围 | 防止跨栏串联 |
| 条目顶部和底部 `y` 范围 | 防止串到上一条或下一条 |
| 公司名、联系人、职务 | 固定被主张的关系 |
| 页面截图或裁剪 | 允许人工复核 |
| 独立来源 | 验证联系人职务或公司关系 |

如果无法证明公司名和联系人位于同一条目边界内，结论只能标为“未确认”。

### 5. 反向检查相邻记录

不仅要看目标条目，还要检查它左、右、上、下的相邻条目。常见纠错方式是：

1. 找到可疑联系人的视觉位置。
2. 沿同一栏向上找到最近的条目编号或公司名锚点。
3. 确认该条目在下一编号前结束。
4. 检查目标公司是否其实位于另一栏。

这一步能直接发现“文本相邻、视觉不相邻”的误配。

### 6. 限制敏感字段

企业名录常同时包含身份证号、税号或其他个人标识。联系人验证只提取完成任务所需的姓名、公开职务和商务联系方式，不复制无关敏感字段，也不把它们写入报告或测试夹具。

## 验证清单

- 已记录 PDF 来源、页码和条目编号。
- 已查看页面渲染图，而不是只看搜索摘要或纯文本。
- 公司名与联系人位于同一栏位和同一条目边界。
- 已检查相邻栏及上一条、下一条，排除跨栏和跨记录串联。
- 程序化提取使用布局或坐标信息，没有依赖固定字符窗口。
- 至少用一个独立来源验证联系人职务；没有独立来源时明确降低置信度。
- 没有把同一联系人无证据地分配给多家相邻公司。
- 报告引用的是“公司—联系人关系”证据，不只是两个名称分别存在。
- 未保留或传播任务无关的身份证号、税号等敏感字段。

## 适用范围

适用于多栏商会名录、企业选民册、协会会员名单、股东/董事清单、政府公报、招标名单和扫描表格。单栏、结构化且可验证阅读顺序的 PDF 不需要完整坐标流程，但仍应保存页码和条目编号。
